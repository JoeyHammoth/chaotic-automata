Verifier

A decider is a guess with a receipt. The cycler, the translated cycler and the bouncer all propose a certificate, and a separate checker — its own parser, its own stepper, no shared code — either replays it and accepts, or refuses it. A machine that reaches the cap with no accepted certificate is not called non-halting: it is either heuristically non-halting (it looks trapped, and that is all) or undecided.

Cryptids: machines nobody can classify

These machines are quoted from the bbchallenge wiki because their halting problem is tied to an open problem. The pipeline runs them for the same 256 steps as everything else and reports what that run is — a guess with no certificate — beside the wiki's own words. A row here proves nothing about halting, and that sentence is in every row. Each row also carries the same walk one decade past the product's budget, run by a separate Rust mirror that the differential tests hold to the producer's numbers; the hollow point is that longer run, not the product's.
